# @vela-admin/contracts

Framework-neutral TypeScript contracts for Vela Admin Kit: async state, pagination, query,
transport, error, permission, storage, and upload boundaries.

```bash
pnpm add @vela-admin/contracts
```

```ts
import { createPagePagination, loadingState } from '@vela-admin/contracts'
```

This package has no Vue or Vuetify runtime dependency. See the Vela Admin Kit documentation for
the complete API and compatibility policy. Licensed under MIT.
