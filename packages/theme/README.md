# @vela-admin/theme

Semantic design tokens, polished Vuetify defaults, light/dark themes, appearance persistence,
density, motion, font scale, contrast, and icon aliases for Vela Admin Kit.

```bash
pnpm add @vela-admin/theme vue vuetify
```

```ts
import { createVelaAppearanceController, createVelaPreset } from '@vela-admin/theme'
import '@vela-admin/theme/styles.css'
```

Applications can replace the brand palette without changing component CSS. Licensed under MIT.
